# MyGrab Free — быстрый запуск

1. Распакуйте **всю** папку в отдельное постоянное место. Для Windows EXE папка `_internal` должна оставаться рядом с `main.exe`.
2. Запустите `1_setup.bat`. В открывшемся `config.json` заполните свои `api_id`, `api_hash`, `bot_token`, `my_id`. Значения выдаются вашим Telegram-приложением на my.telegram.org и вашим ботом через @BotFather. Числа указываются без кавычек, строки — в двойных кавычках.
3. Для модерации укажите ID закрытого технического канала в `technical_channel_id`. Если она не нужна, оставьте `0`. Аккаунту и боту нужны права публикации в этом канале.
4. `new_link` и `new_username` — одна общая замена ссылки и упоминаний. Пустая строка сохраняет исходные значения. `language`: `ru` или `en`.
5. Сохраните конфигурацию. Запустите `2_authorize.bat`, введите телефон своего аккаунта, код Telegram и пароль двухэтапной проверки, если он включён.
6. Закройте окно авторизации. Запустите `3_start.bat`, затем `/start` в вашем боте с аккаунта владельца из `my_id`.
7. Добавьте тестовый источник, тестового получателя и соответствие. Опубликуйте новый пост в источнике и проверьте результат.

Аккаунт должен читать источники и иметь право публикации в получателях. Компьютер должен работать, программа — оставаться открытой. Не запускайте два экземпляра в одной папке. Для EXE установка Python не нужна; для исходников нужен Python 3.11 x64.

Команды:

```text
/add_channel -1001111111111
/add_destination_channel -1002222222222
/set_channel_mapping -1001111111111 -1002222222222
/last_messages -1001111111111 5
/pending
/cancel_copy
/help
```

Новые посты принимаются после запуска. Старая история автоматически не догоняется. Историю копируйте только отдельной командой; каждый источник отправляется по своему соответствию. В Free один получатель на источник. Настройки и очередь хранятся в `mygrab_free.db`.

В Free кастомные эмодзи заменяются обычным Unicode-символом. Сохранение кастомных эмодзи через доработанный addon, фильтры, несколько получателей и расширенные настройки доступны в Premium.

Premium — 4 000 ₽ за текущую версию. Возможна оплата в криптовалюте по согласованию. Валюту, сеть, сумму и реквизиты согласуйте лично до оплаты: **@every_manager**. Канал проекта: **@mygrab_tg**.

Проверка установки без Telegram: `main.exe --self-check` или `python main.py --self-check` для исходников. Проверка заполненной конфигурации: `--check-config`. Общий лог: `mygrab.log`.

Остановка — `Ctrl+C`. Перед резервным копированием остановите программу и скопируйте всю её папку. Файлы `config.json`, `MyGrab_Free.session`, `mygrab_free.db` и логи не передавайте другим людям и не загружайте в GitHub. Старые конфигурации `.py` и `.pickle` не импортируются автоматически.
