## Установка Free для Windows — без Python

1. Скачайте **[MyGrab_Free_Windows.zip](https://github.com/GrabberTG/telegram-grabber-bot/releases/latest/download/MyGrab_Free_Windows.zip)** из [последнего релиза](https://github.com/GrabberTG/telegram-grabber-bot/releases/latest) и распакуйте целиком в новую постоянную папку (правой кнопкой → «Извлечь всё»). Рядом с `main.exe` должна остаться папка `_internal`.
2. Запустите **`1_setup.bat`**: откроется `config.json`. Заполните свои данные по таблице ниже и сохраните файл.
3. Запустите **`2_authorize.bat`**. Введите телефон аккаунта, код Telegram и пароль двухэтапной проверки, если он включён. Не держите одновременно открытым другой экземпляр этой программы.
4. Закройте окно авторизации и запустите **`3_start.bat`**.
5. Откройте созданного вами бота и отправьте `/start` от аккаунта владельца.

Проверка архива: [VirusTotal](https://www.virustotal.com/gui/file/ed4352837c8796202bd97ccb1545d0723466301c248296ac0d98d462ea4d6787) · SHA-256 в [`SHA256SUMS.txt`](SHA256SUMS.txt). EXE включает Python и библиотеки. Установка системного Python для этого варианта не нужна. Это сборка для **Windows x64**.

## Запуск из исходников Python

Скачайте репозиторий через **Code → Download ZIP**, распакуйте в отдельную папку и установите **Python 3.11 x64 с Python Launcher** с [python.org](https://www.python.org/downloads/windows/). Затем используйте те же три файла запуска: `1_setup.bat`, `2_authorize.bat`, `3_start.bat`.

Первый файл создаёт отдельное окружение и устанавливает точные версии библиотек из `requirements.txt`. Самостоятельный запуск:

```powershell
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item config.example.json config.json
# Заполните config.json перед следующей командой.
.venv\Scripts\python.exe main.py --authorize
.venv\Scripts\python.exe main.py
```

Команда копирования примера предназначена для новой установки: не заменяйте уже заполненный `config.json`.

## Настройки подключения

Создайте собственного бота через [@BotFather](https://t.me/BotFather), а `api_id` и `api_hash` получите для своего приложения на [my.telegram.org](https://my.telegram.org).

| Поле `config.json` | Значение |
|---|---|
| `api_id` | Ваш числовой API ID без кавычек |
| `api_hash` | API hash, строка в кавычках |
| `bot_token` | Токен вашего бота |
| `my_id` | Числовой ID владельца; только ему доступно управление |
| `technical_channel_id` | ID отдельного закрытого канала с `-100` для модерации; `0`, если модерация не нужна |
| `new_link` | Общая новая ссылка вида `https://…`; пустая строка отключает замену |
| `new_username` | Ваш `@username`; пустая строка сохраняет исходные упоминания |
| `language` | `ru` или `en` — язык меню |

Авторизованный аккаунт должен состоять в источниках и иметь право публикации в получателях. Для модерации дайте аккаунту права публикации/редактирования в техническом канале, а боту — право отправлять туда сообщения с кнопками. Технический канал нельзя использовать как источник или получатель.

Новая Free использует `config.json` и `mygrab_free.db`; старые `config.py` и `.pickle` автоматически не импортируются. Настройте её отдельно от старого EXE. Не переносите чужие Telegram-сессии.

## Как настроить автоматическую пересылку между каналами

В меню `/start` добавьте источник, получателя и соответствие. Можно указать `@username` или полный числовой ID. Пример команд:

```text
/add_channel -1001111111111
/add_destination_channel -1002222222222
/set_channel_mapping -1001111111111 -1002222222222
/show_mapping
```

Отправьте **новый** пост в источник. Автоматический режим принимает сообщения, появившиеся после запуска программы. История за время остановки не догоняется автоматически.

Компьютер должен быть включён, программа запущена, а оба подключения Telegram доступны по сети. Free не содержит настроек прокси; доступ к сети обеспечивается на стороне компьютера. Выделенный сервер для домашнего запуска не нужен.

## Как скопировать историю Telegram-канала

```text
/last_messages -1001111111111 5
/last_messages 5
/last_messages -1001111111111 all
/cancel_copy
```

Первая команда обрабатывает пять последних сообщений выбранного источника **только в его получатель**. Вторая — по пять сообщений каждого настроенного источника, каждый по своему маршруту. `all` обрабатывает доступную историю. Альбом отправляется целиком и считается одной отправкой; крайний альбом может включить сообщения за границей указанного N.

Между обработанными постами ручной истории есть фиксированная пауза в одну секунду. Ожидания Telegram выполняются дополнительно. Итог отдельно показывает отправленные, поставленные на модерацию, пропущенные и ошибочные посты. Новые автоматические сообщения обрабатываются параллельно; отправки в один получатель согласуются между собой.

## Модерация публикаций

Укажите технический канал и включите модерацию в меню. Подготовленный пост и кнопки появятся в этом канале. Можно изменить текст или подпись предпросмотра, затем нажать «Опубликовать». При редактировании нескольких подписей альбома их текст объединяется в одну подпись. Замена самого медиа через предпросмотр не поддерживается.

`/pending` показывает сохранённую очередь. После перезапуска состояние модерации и ожидающие посты сохраняются. Если предпросмотр не отправился из-за сети, запись остаётся в очереди. Подтверждать и отклонять посты может только владелец.

## Частые вопросы

### Что такое граббер Telegram?
Это программа, которая сама копирует новые посты из выбранных Telegram-каналов в ваши каналы. MyGrab — бесплатный граббер с открытым кодом: автопостинг, репост без пометки «Переслано из», замена ссылок и модерация.

### Как автоматически переслать посты из чужого канала в свой?
Ваш аккаунт должен состоять в канале-источнике, а в своём канале — иметь право публикации. Добавьте источник и получатель в меню бота и свяжите их. Новые посты будут копироваться сами, пока программа запущена.

### Можно ли копировать закрытый (приватный) канал?
Да, если ваш аккаунт состоит в этом канале. Если владелец канала запретил копирование контента, Telegram может не дать отправить медиа из него.

### Посты будут с пометкой «Переслано из»?
Нет. Пост публикуется от имени вашего канала как новое сообщение — без ссылки на источник. Ссылки и `@username` можно заменить на свои.

### Нужно ли быть админом в канале-источнике?
Нет. Достаточно, чтобы ваш аккаунт был подписан на источник. Права публикации нужны только в ваших каналах-получателях.

### Это бесплатно?
Да. MyGrab Free бесплатен, без подписки и без рекламы в ваших постах. Расширенные функции — в [Premium](#купить-mygrab-premium).

### Нужен ли сервер или VPS?
Нет. Достаточно компьютера с Windows, на котором запущена программа. Для работы 24/7 можно использовать VPS с Windows или запустить исходники на Python.

### Как скопировать старые посты канала?
Командой `/last_messages` — подробнее в разделе [«Как скопировать историю Telegram-канала»](#как-скопировать-историю-telegram-канала).

### Антивирус ругается на main.exe — это вирус?
Нет. Программы, собранные PyInstaller, антивирусы иногда помечают ошибочно. Код полностью открыт в этом репозитории. [Отчёт VirusTotal](https://www.virustotal.com/gui/file/ed4352837c8796202bd97ccb1545d0723466301c248296ac0d98d462ea4d6787) для архива релиза: 1 из 66 — эвристика Zillya, остальные 65 антивирусов угроз не нашли. Если сомневаетесь — запустите программу из исходников Python.

### Это безопасно для моего аккаунта?
Программа работает на вашем компьютере, ваши ключи и сессия никуда не отправляются. Telegram может ограничивать слишком частые отправки, поэтому не копируйте огромные архивы без пауз.

## Проверка и сохранение данных

Для проверки установки без подключения к Telegram:

```text
main.exe --self-check
```

Для исходников: `py -3.11 main.py --self-check`. Автоматические проверки: `python -m unittest discover -s tests -v` в установленном окружении. Они проверяют логику с подставными подключениями; проверку реальной сети и прав каналов нужно провести отдельно.

Перед первым использованием проверьте программу на двух тестовых каналах. Остановка — `Ctrl+C`. Для резервной копии остановите программу и сохраните всю её папку. `config.json`, `MyGrab_Free.session` и `mygrab_free.db` содержат ваши данные — не публикуйте их. Сбой связи в момент подтверждения отправки может потребовать проверки канала перед повторной попыткой.

Программа работает с каналами, доступными вашему аккаунту, и не гарантирует отсутствие ограничений Telegram.
